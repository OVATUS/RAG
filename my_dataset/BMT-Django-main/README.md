## ภาพรวม (Overview)
BMT เป็นเว็บแอปพลิเคชันที่พัฒนาด้วย Django สำหรับการจัดการจองสนาม ผู้ใช้สามารถสมัครสมาชิก, เข้าสู่ระบบ, ดูสนามที่ให้บริการ, ทำการจอง, รวมถึงจัดการประวัติการจองและโปรไฟล์ส่วนตัวได้ 

## Features
- **การจัดการผู้ใช้งาน (User Authentication)**: ระบบสมัครสมาชิก, เข้าสู่ระบบ, และจัดการโปรไฟล์, ปิดใช้งานบัญชี
- **การจัดการสนาม (Court Management)**: ดูรายละเอียดของสนามที่ให้บริการ 
- **ระบบการจอง (Booking System)**: ผู้ใช้สามารถจองสนาม, แก้ไขการจอง, ยกเลิก และ ดูประวัติการจองของตนเองได้

## โครงสร้างโปรเจค 
โปรเจคนี้ถูกแบ่งออกเป็นแอปพลิเคชัน:
- `users_bmt/`: จัดการข้อมูลโปรไฟล์ผู้ใช้, การเข้าสู่ระบบ, และการสมัครสมาชิก
- `courts_bmt/`: จัดการข้อมูลของสนาม รวมถึงการแสดงรายละเอียดและรายการสนามทั้งหมด
- `booking_bmt/`: จัดการตรรกะของการจอง, สถานะการจอง, และประวัติการใช้งาน
